# ПЕНОПЛЭКС Технарь

Обновление 30.10.2026: согласованная модель L3, новая цветопередача и мягкий свет, галерея архитектурных изображений, облегчённые ресурсы и отформатированный код. [Измерения, изменения и границы проверки](PERFORMANCE.md).

[Открыть сайт](https://xoxlomaaa.github.io/penoplex-tehnar/)

Интерактивный разрез строительной системы **СТИЛОБАТ V2.0**: вращение 3D-модели, выбор и изоляция 12 слоёв, плавное разнесение конструкции, карточки материалов, пошаговое знакомство и техническая документация.

Модель, рендеры, шрифт Geologica, изображения материалов и PDF находятся в репозитории. Экспорт текущего вида в PNG и состава системы в CSV выполняется в браузере.

## Локальный запуск

Нужен Node.js 20 или новее. Установка зависимостей не требуется.

```sh
npm run dev
```

Открыть http://127.0.0.1:3300/.

```sh
npm run check
npm test
npm run build -- /penoplex-tehnar/
```

Сборка находится в `dist/`. Проверить её локально:

```sh
node tools/serve.mjs dist 3301 /penoplex-tehnar/
```

Открыть http://127.0.0.1:3301/penoplex-tehnar/.

## Публикация

GitHub Actions проверяет проект, создаёт статическую сборку с путями для подпапки репозитория и публикует её в GitHub Pages после изменений ветки `main`. В настройках Pages выбран источник **GitHub Actions**.

## Устройство

- `public/` — страница, интерфейс, 3D-сцена и все ресурсы.
- `public/content.js` — состав системы, материалы и документы.
- `public/viewer.js` — Three.js, выбор, вращение, разнесение и экспорт.
- `public/state.js` — сохранение ракурса и выбранного слоя в ссылке.
- `tools/` — проверка, сборка и локальный сервер без зависимостей.

Модель загружается по запросу: 39,5 МБ для ПК, 32,7 МБ для узкого экрана или экономии трафика. Галерея и постер используют адаптивный WebP, Geologica — WOFF2. Геометрия исходной L3 сохранена побайтно; на телефоне разрешение текстур ограничено 512 px. На медленном интернете загрузка 3D всё ещё требует времени. Геометрия служит для наглядного изучения конструкции; инженерные параметры подбираются по проекту. Расчёт нагрузок, стоимости и объёмов не выполняется.

`public/studio-lighting.js` содержит утверждённый свет, `public/model-assets.js` — выбор ресурса, `public/about-gallery.js` — галерею. Кадры 3D запрашиваются по необходимости; в неподвижном состоянии цикл останавливается. `npm test` включает три проверки ссылок состояния и выбора мобильной модели. Публикация не требует npm-зависимостей: подготовленные файлы ресурсов уже находятся в репозитории.
