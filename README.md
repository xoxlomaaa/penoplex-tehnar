# ПЕНОПЛЭКС Технарь

[Открыть «Благоустройство»](https://xoxlomaaa.github.io/penoplex-tehnar/)

Четыре системы по перекрытию с интерактивными разрезами, сценами применения и техническими документами.

## Локальный запуск

```sh
npm run build
npm run check
npm test
npm run dev -- --port 3205
```

Сборка и проверка используют Node.js 24. Node выводит адрес локального просмотра. Ветки и сборки GitHub Pages используют версионированные пути к статическим файлам.

## Публикация

Workflow в `.github/workflows/pages.yml` собирает сайт для пути репозитория, запускает проверки и публикует каталог выпуска после обновления `main`.
